## 一、量的是什么、不量什么

- **量**：`check_prompt_quality` 的 7 条确定性规则（`meta_leak` / `context_leak` /
  `blanket_missing_branch` / `delimiter_unbalanced` / `too_short` / `constraint_overload` /
  `suppressive_rule`）与 `diff_prompts` 的 `regressed` 判决（`gate` 同源）在语料上的混淆计数。
- **判据同源**：测量直接调 `pm.quality` / `pm.promptdiff`，与 `check`/`diff`/`gate` 用同一把尺子，
  不另写一套。
- **不量**：评委判别力（§三十一 那本账）；`--cases-file` 的结构统计（那是计数不是分类器，
  有自己的守卫）；注入装束对公开分类学的覆盖（PE-6 另表）。
- **label 语义**：「这条文本是否真有该类缺陷」的人工判定，**独立于实现**。
  实现命中而 label 为假 = 误报（FP）；label 为真而未命中 = 漏判（FN）。

## 四、这张表曾指出的三件事（1、2 已修，3 是合同边界）

1. **`delimiter_unbalanced` 精确率曾为 0.500 —— 两例真实误报（R38 / R42）。✅ 已修（2026-11-15）。**
   形态：示例行里「行中开标签 + 行尾闭标签」（如 `输入：<客户对话>…</客户对话>`）。
   `_structural_tags` 的行边界判据只认行首/行尾 ⇒ 闭标签被计入结构、配对的开标签没有，
   于是报「没有对应的开标签」；当时对真实交付物的命中**三里两假**。
   修法：`delimiter_problems` 逐行先用 `_INLINE_PAIR_RE` 摘掉**同一行、同名、成对**的
   `<X>…</X>`，再走原有 stack 判据。跨行结构标签、重复开标签、孤儿闭标签一律不动 ——
   C22 / C23 / P10 三条正例与 `tests/test_quality.py` 的 Run A 事故形态仍全部命中，
   `test_inline_balanced_example_is_not_a_delimiter_problem` 反向钉住「不许靠一律放行刷精确率」。
2. **`suppressive_rule` 召回曾为 0.667 —— 一例漏判（C14）。✅ 已修（2026-11-15）。**
   同一行内的两个英文撇号（`Don't … user's`）会把中间的抑制句当「引用」吞掉。
   2026-10-31 只修了跨行（`[^'\n]`）；本轮给单引号分支两侧加锚
   `(?<![A-Za-z0-9])` / `(?![A-Za-z0-9])`：英文缩写/所有格的撇号前后紧贴字母，
   不再冒充引用边界，而真正的成对英文引用（`不写 '停止处理' 这类条款`）仍照旧剥离。
   C11 / C12 / C13 三条正/负例与 `tests/test_quality.py` 原有引用用例全部保持原判。
3. **gate 合同符合 10/10，但 P08 钉住一个已知盲区（未改，属当前合同）。**
   已命中 code 内的计数增长（约束 10→12 条）对 `regressed` 判决不可见（结构通道可见 +2，
   门禁不行动）。按当前文档合同这是「正确行为」，但读者应当知道：**gate 绿不蕴含约束数没涨**。

## 六、标注协议与诚实边界

- 标注由本轮作者完成，**非盲标**（读过实现与全部注释）⇒ 读数是「实现与标注合同的自洽性」，
  **不是外部效度**；对抗负例是构造时就知道该放行的，表B 的「仅真实」列才是误报率的诚实分母。
- 真实文本全量收录、无一挑选；12 条命中文本的逐条判定（含两例误报）理由见语料 JSON 的
  `labels` 与本文第四节。
- 规则判据全部确定性：同语料同实现下读数可精确复算；实现或语料一变，守卫测试会红。
- **测量轮（2026-10-29）只测量、不修规则**；修复落在 2026-11-15 独立轮次
  （行为变更 + 变异验证），基线读数因此留住了。前后两张表可直接对照：
  `delimiter_unbalanced` 精确率 0.500→1.000、`suppressive_rule` 召回 0.667→1.000，
  其余五条规则与 gate 前后对 10/10 一字未动。
- **满分不等于外部效度**：语料仍是同一份 101 条、标注非盲标。7 条规则全满分只说明
  「实现与本语料的标注合同自洽」，不说明提示词缺陷都被抓全了 —— 第五节的射程外盲区
  （HTML 注释形式的过程标记、邀请编造数据的措辞、抑制句换说法）一条都没补。
