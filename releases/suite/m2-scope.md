# M2 运维感知里程碑 · 目标与范围说明

日期：2026-09-22 晚 · 执行人：Agent-AutoClaw · 窗口：单会话内完成

## 背景

能力地图 v2（capability-map-v2.html）标注了三项"可直接开工"项：告警落盘但送达不了人、pending 任务超时无人提醒、成本数据有但不是实时的。三者同属"运维感知能力"，合并为本里程碑一次交付。

## 范围

**做（三项最小可用增量）**：
1. **M2.1 通知中心**：告警分发升级——除落盘 notifications.jsonl 外，支持 webhook 推送（可配置 URL，非必填），并提供通知查看页 `/static/notifications.html`
2. **M2.2 pending 超时提醒**：看门狗巡检时检查任务台账，pending/待用户超 24h 的任务落告警通知
3. **M2.3 实时调用曲线**：成本看板页增加实时面板（每 5s 拉网关 /v1/metrics，SVG 折线图展示累计调用增长）

**不做**：接入具体 IM/邮件服务商（需账号授权，另行确认）；鉴权；龙虾内容；数据库迁移——均维持既有触发条件。

## 关键假设

- webhook 目标 URL 由用户后续填入 `data/notify_config.json`（本期只留机制不填目标，空配置=仅落盘，零副作用）
- 实时曲线用网关 /v1/metrics 累计值，经会审台代理端点转发（避免浏览器跨域）
- 看门狗已有 5min 巡检节奏，超时提醒复用该通道，不新建计划任务

## 成功标准

1. 三项功能各有真实运行证据（API/页面/通知落盘）
2. 旧测试套件回归全过（无破坏）
3. 至少演练一条异常路径（webhook 不可达时静默不崩）
4. 回滚路径：git tag v1.4.2 单提交回退 + 文件级 .bak
