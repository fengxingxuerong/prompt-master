# extras/ —— 可选附件

这里的东西**不随 `pip install .` 安装**，也不在 CI 主门禁里。它们服务的是"想点开看看"的场景，
不是被集成的接口；主包只背 CLI / REST / MCP 三条。

## desktop.py —— 原生桌面窗口（Tkinter）

```bash
python run.py desktop                         # 从仓库根运行；pm/desktop.py 只是转发壳
python run.py desktop --project-dir D:\my-app  # 启动时预填项目文件夹
python run.py desktop --prompt-file 我的提示词.md  # 启动时预填已有提示词
python extras/desktop.py                      # 直接从附件启动（会自己读仓库根的 .env）
pytest tests_extras -q                        # 附件回归；窗口层需要本机有 tkinter
```

**2026-10-20 重做为“读项目，写提示词”**。上一版仍是“粘贴提示词 → 体检 → 报价 → 跑优化闭环”，
对人类用户来说还是要理解太多概念。现在窗口里只有三个输入和两段输出：

    项目文件夹（可选） + 目标（可选） + 已有提示词（可选）
    →  只读扫描项目  →  模型分析进度  →  可直接复制的新提示词

- **只读取项目（免费）**：零模型调用，列出文件统计、目录、重点文件、Git 提交、未提交改动和
  TODO；不需要 API Key。
- **项目文件夹两种填法都行**：点「选择文件夹…」挑，或把路径直接粘贴进去（资源管理器
  「复制文件地址」带的引号、`file:///` 前缀、首尾空格都会自动收拾；粘的是文件则自动改用
  所在文件夹）。输入框下方实时给 `✓ 已选中 · 顶层 N 项` / `✗ 路径不存在`。
- **读取项目并生成提示词**：需要 `PM_API_KEY`（或 `PM_OPTIMIZER_API_KEY`），会做**一次模型分析**
  （格式/空正文失败时由调用层自动重试，按实际请求计费）；结果同时过一遍 `pm/quality` 的零调用规则体检。
- 没有 Key 时按钮会置灰并写明原因；不会偷偷发请求。
- 两块结果**各有自己的**「复制 / 另存为…」：**项目进度**和**提示词**都导得出来
  （2026-10-21 修：原先导出只认提示词，免费扫描读完项目后点「另存为…」会得到一句
  "还没有可保存的提示词"，刚读出来的进度一个字也拿不走）。
  `Ctrl+S` 存提示词；没有提示词时（只做了免费扫描）存项目进度，状态行会写明存的是哪块。
- 取消会终止后端子进程；关闭窗口时若任务还在跑会先确认。

### 三个文件的分工

| 文件 | 做什么 | 边界 |
|---|---|---|
| `desktop.py` | Tkinter 单页窗口、线程/队列、结果渲染 | 不产生判据，不直接拼模型请求 |
| `project_agent.py` | 扫描 → 一次结构化调用 → 规则体检；也可当独立 CLI | 输出单个 JSON；无 Key 只允许 scan-only |
| `project_context.py` | `list_files` / `read_file` / `search_text`、Git 快照、TODO | 只读；路径必须留在根目录内；密钥与依赖目录跳过 |

```bash
# 后端也能单独跑：先看项目，不花钱
python extras/project_agent.py --project-dir D:\my-app --scan-only --json
# 生成提示词（需要 Key）
python extras/project_agent.py --project-dir D:\my-app --goal "实现支付" --json
```

### 隐私与安全（明说）

- 只读：窗口和后端都不修改用户项目。
- 自动跳过 `.env*`、私钥/凭据文件、`.ssh/.aws` 一类目录，以及 `node_modules`、`.venv`、
  `build` 等依赖/产物目录；普通源码里出现的已知凭证形态在离开扫描层前会被脱敏。
- 目录树、关键文件数量与总字符数都有硬上限；不会把整个仓库塞给模型。
- **选中的关键文件内容摘录仍会发送给模型提供方**。请不要把密钥写进提示词，也不要把不愿外发的
  项目交给第三方模型。

### 与主产品的关系

桌面端不再跑“用例 → 评分 → 基线 → 修订”的完整闭环。考卷、差分、账本、评委仪表与报价
仍在 CLI / REST / MCP 里，一样都没少；这里只是不再把它们塞进小白窗口。

### 为什么从主包移出（2026-10-19）

它是 Tkinter 代码，占产品代码约 8%，却只服务一个非集成入口。移出后：

- 主包不再需要 tkinter / 显示器相关依赖；
- CI 主套件不再受窗口层 skip 影响（历史上它曾把 Linux 覆盖率从 96.99% 拉到 89.66%）；
- `run.py desktop` 仍然可用（`pm/desktop.py` 转发到本文件），既有用户不被静默拿走功能。

### 代价（明说）

- **附件没有门禁**：改坏了不会有人红。手动跑 `pytest tests_extras` 是唯一保护。
- **装包态不可用**：`pip install .` 之后 `prompt-master desktop` 会给出提示并返回 2，
  因为 `extras/` 不在 wheel 里。要长期用就从检出目录跑，或 `pip install -e .`。
