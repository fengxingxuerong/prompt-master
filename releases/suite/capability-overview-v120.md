## 一、现在能用什么（逐项附入口与用法）

### 1. 统一 LLM 模型池网关 — ModelHub（127.0.0.1:8687）
- **能干嘛**：给任何应用一个稳定的多模型调用入口。15 个 LLM（商汤/AMD/阶跃/NVIDIA/OpenRouter 5 路上游）按优先级自动调度，单家 429/超时自动熔断切换；坏模型名 <0.1s 快速失败。
- **入口**：`POST /v1/chat/completions`（OpenAI 兼容格式，`model` 填池内任意名字）；`GET /v1/models` 看池；`GET /v1/pool/status`、`/v1/metrics`、`/v1/ledger/stats` 看运行态；`GET /console` 网页控制台。
- **本轮实测**：C1 15 models / C2 真实调用 6390ms 正常 / C3 池状态 15 条目 / C4 累计 128 调用（121 成功，含已知 NVIDIA 超时熔断）。
- **边界**：OpenRouter 欠费禁用中；NVIDIA 冷启动慢（熔断兜底）；流式转发有已知 P1 问题（TASK-002 等你的商汤口径）。

### 2. 多模型会审台 — Triage（127.0.0.1:8793）★v1.2.0 新形态
- **能干嘛**：客服工单秒级受理、6 个 LLM 评委并行研判（分类/严重度/动作/置信度）、共识汇总、人工反馈闭环。**提交 31ms 即返回**（旧同步 60.4s），前端 SSE 实时看每位评委出票。
- **入口**：浏览器开 `http://127.0.0.1:8793/`（提交工单→实时逐票→共识→反馈一条龙）；API `POST /api/reviews`（异步）/ `?wait=1`（同步兼容）/ `GET /api/sessions/{sid}/events`（SSE）/ `GET /api/ledger`（调用台账）/ `POST /api/sessions/{sid}/feedback`。
- **本轮实测**：C8 异步 31ms / C9 SSE progress=6+done=1 / C10 终态 technical/P3（majority_at=2.4s）/ C11 wait=1 兼容 PASS。
- **边界**：会审本身仍需等评委（快票 2.4s 即汇总，慢源 late 票不阻塞）；UI 深色风格、无鉴权。

### 3. 用量成本看板 ★新增
- **能干嘛**：看每天调了多少次、成功率、总耗时、按模型分布——成本审计有据可查。
- **入口**：`http://127.0.0.1:8793/static/cost-board.html`（数据源 `GET /api/usage-board`，只读 usage_daily.json）。
- **本轮实测**：C12 days=1 total_calls=25 success=25（100%）/ C13 页面 5207 字符。
- **边界**：单日数据（usage_daily 按 日滚动）；成本按调用数与 token usage 口径，未接价格表。

### 4. 任务台账 — Taskboard（127.0.0.1:8792）

### 5. 演示电商站 — 龙虾（127.0.0.1:8791）
