03怎么把项目跑起来（从零）

前置：Python 3.12 · Windows（PowerShell）
① 依赖：pip install -r requirements.txt（项目根）
② 配置：.env 填 PM_API_KEY（商汤）/ PM_API_KEY_AMD / PM_API_KEY_STEP 等；config/modelhub.json 定义模型池
③ 启动：python run_modelhub.py --port 8687  |  python releases/lobster/app.py --port 8791  |  python releases/taskboard/app.py --port 8792  |  python releases/triage/app.py
④ 验证点：GET :8687/v1/models → 15 条目；GET :8793/api/health → v1.1.1；四服务 /api/health 全 ok
⑤ 保障：schtasks 注册 SuiteWatchdog（onstart+5min）后自动巡检拉起
常见故障：端口占用 → netstat 找 PID；上游 429 → 熔断冷却自动恢复；usage 文件损坏 → .corrupt 留存自动重建
