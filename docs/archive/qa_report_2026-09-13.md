## 七、遗留风险

1. **已更正**：原 P2-3（终态后取报告 404）经复核为**测试客户端走了本机代理**（Clash 拦截 127.0.0.1）导致的伪 404，服务端无此缺陷；已补直连回归用例锁定。教训：本机验证必须带 `--noproxy '*'` / `no_proxy=127.0.0.1,localhost`，否则会把代理行为误判成服务缺陷。
2. **未覆盖环境**：`Dockerfile` 未经构建；浏览器级 CSP 验证（playwright 缺失）本次以 HTTP 头 + 页面源码静态核验替代，未做运行时 `cspViolations` 抓取。
3. **评委独立性**：本次评委 B 为异家族模型（sensenova/deepseek-v4-pro），结论有效；若部署时 A/B 同源，盲评与双评委的可信度会显著下降（README 已知限制）。
4. **成本与限流**：真实调用 82 次未触发 IP 级限流，但 Run A 47 分钟已接近风险区间；批量测试需错峰（README：冷却需 5 分钟以上）。
5. **修订器在思考型模型上的空返回**：前一日 glm-5.2 复测未能复现（4000 预算亦正常），根因仍未定性，需在新模型/新负载下持续观察。
6. **注入存活检测**：本次 Run A 使用种子用例（无 scenario），未再产生注入用例；该能力仅在前一日真实运行中验证过 1 轮，样本仍偏少。
