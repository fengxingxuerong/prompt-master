# ModelHub v1.0.0 发布测试计划

> 日期：2026-09-21 · 被测对象：D:\projects\prompt-master（ModelHub 统一模型池网关）
> 环境约定：本机运行中的网关（127.0.0.1:8687）即为预发布环境；公网流量切换不在本轮范围（Goal Brief outOfScope）。

## 1. 性能基线（口径适配声明）

Goal Brief 默认基线"首屏 ≤3s / 关键操作 ≤1s"面向网页产品；本产品是 LLM 网关，
响应时间由上游模型推理主导（实测 2s–40s 不等），该口径不可直接套用。
按"可控指标"适配如下（替代基线，作为验收依据）：

| 指标 | 基线 | 说明 |
|---|---|---|
| 网关转发开销 | ≤200ms/次 | 同模型同请求，经网关 vs 直连上游的中位延迟差（网关自身 Python/FastAPI 开销） |
| 并发正确性 | 8 路并发 100% 成功 | 并发对话无串账（agent/request_id 一一对应）、无未处理异常 |
| 进程稳定性 | 连续测试后 /api/health 正常 | 无内存暴涨、无死锁 |

## 2. 测试矩阵

| 层 | 用例组 | 数量 | 方式 |
|---|---|---|---|
| 单元 | 池配置加载/占位符解析/损坏配置 | U 组 | 临时配置文件 + 独立进程 |
| 单元 | 断路器：连败熔断/冷却跳过/自愈放行 | U 组 | 直接操纵 ModelHub 状态 |
| 单元 | 台账：六维检索过滤、坏行容错 | U 组 | PMH_LEDGER_PATH 指向临时台账 |
| 单元 | 角色：渲染/未知角色报错；智能体注册/注销 | U 组 | 临时 roles 文件 |
| 网关 | 并发：8 路并行对话 + 台账归属一致性 | C 组 | 线程池打真实网关 |
| 性能 | 转发开销（直连 vs 网关各 4 次）+ 并发吞吐 | P 组 | 计时对比 |
| 冒烟 | 模型清单/角色/注册/对话/台账全链路 | S 组 | 复用 e2e_test.py 全量回归 |

## 3. 缺陷分级

- S1 致命：主链路不可用 / 数据串账 / 静默失败 —— 必须清零才可发布
- S2 严重：功能错误但有兜底报错 —— 必须修复或明确缓解
- S3 一般：体验/文档/口径问题 —— 记录并给出处理结论
- S4 建议：优化项 —— 记入已知问题即可

## 4. 通过标准

单元/网关/冒烟全部用例执行且通过；S1/S2 缺陷清零（修复并回归验证）；
性能达 §1 基线；发布检查清单逐项复核留痕；回滚演练成功。
